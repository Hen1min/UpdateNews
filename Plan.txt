# 智能监控机器人项目计划书

## 项目概述

### 主要功能

- 每隔一定时间从指定网站的指定部分抓取更新内容
- 通过CSS选择器定位需要监控的内容区域
- 第一次运行时保存初始内容，后续运行时进行对比检测更新
- 检测到更新后通过AI分析提取关键词和摘要
- 将结果保存为txt文件并通过QQ发送通知

### 工作原理

1. 检测最晚已记录内容的上传时间（年月日时分秒）
2. 从该时间段往后检测是否有更新内容
3. 抓取的更新内容通过AI进行分析处理
4. 结果保存为txt文件（同天内容保存在同一文件中）
5. 通过QQ小号发送结果给指定接收方

## 技术实现方案

### 技术栈选择

- **爬虫工具**：Requests + BeautifulSoup4
- **AI分析**：OpenAI Python SDK（或兼容API）
- **界面设计**：CustomTkinter
- **定时任务**：threading.Timer
- **配置管理**：JSON文件
- **打包工具**：Nuitka

### 核心功能模块

#### 1. 爬虫模块

- 使用Requests获取网页内容
- 使用BeautifulSoup4解析HTML
- 通过CSS选择器定位指定内容区域
- 支持内容对比和更新检测

#### 2. AI分析模块

- 调用OpenAI API进行文本分析
- 提取关键词和生成摘要
- 支持多种AI模型接口

#### 3. 界面模块

- 使用CustomTkinter创建现代化界面
- 支持URL和CSS选择器输入
- QQ账号配置界面
- 保存路径设置
- 开始/停止控制按钮

#### 4. 任务调度模块

- 使用threading.Timer实现定时任务
- 每30分钟自动检查更新
- 支持手动测试爬取功能
- 多线程处理避免界面卡死

## 核心逻辑实现

### 首次运行处理

- 检查快照文件是否存在
- 如果不存在，保存当前内容并退出，不发送通知
- 避免将历史数据误认为更新

### 内容更新检测

1. 获取当前网页内容
2. 与上次保存内容进行对比
3. 检测到变化则进行后续处理
4. 更新快照文件

### 结果处理流程

1. AI分析提取关键词和摘要
2. 按日期保存为txt文件
3. 通过QQ发送结果通知
4. 支持多个接收方账号

## 注意事项

### 首次运行问题

- 程序首次运行时，last_snapshot.txt文件不存在
- 逻辑修正：在doCheck里判断快照文件是否存在
- 如果不存在，直接保存当前内容并退出，不发送消息

### CSS选择器验证

- 添加"测试爬取"按钮验证选择器
- 确认能正确抓取内容后再开始运行
- 避免因选择器错误导致内容为空

### 多线程处理

- 耗时操作放在后台线程执行
- 避免界面卡死
- 使用threading模块实现
